# UCC 洗衣店小程序

微信小程序项目，包含顾客端、店主端、云函数和本地测试。顾客自行送取，门店核价并线下收款，不含在线支付。

## 项目结构

- `miniprogram/`：小程序页面与静态资源。
- `cloudfunctions/uccLaundry/`：云函数及订单业务逻辑。
- `tests/`：本地模拟测试，不连接真实微信云环境。
- `使用说明.md`：现有环境配置、历史记录与操作说明。
- `上线准备版交付与待办.md`：0.9.7 交付情况及上线前待办；该文件中的后台状态是当时的记录。

## 本地验证

安装 Node.js 后，在项目目录运行：

```powershell
Get-ChildItem tests/*.test.js | ForEach-Object { node $_.FullName; if ($LASTEXITCODE -ne 0) { throw "测试失败: $($_.Name)" } }
```

使用微信开发者工具打开本项目。部署云函数时按开发者工具提示在云端安装依赖，配置和权限要求见 `使用说明.md`。

## 个体工商户主体上线准备

当前配置仍指向原个人主体 AppID 和既有云环境。新账号启用前，应核对新 AppID、云环境、云函数、数据库权限、订阅消息模板及店主身份绑定，避免误操作原有共享云环境。新 AppID 下用户身份标识会发生变化，历史订单与图片不能仅靠复制代码迁移，必须另行制定安全迁移方案并核验。

截至用户提供的通知，原账号的用户隐私保护指引于 2026-10-30 审核通过；原账号的备案、名称、搜索限制和发布状态以微信后台实时结果为准。若改用新主体，应按新账号实际要求重新检查备案、类目、隐私与审核。

仓库不包含订单数据库、门店图片备份或体验二维码。业务数据备份需要通过安全方式单独保存和验证。
